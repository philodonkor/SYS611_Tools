Stage 2 of 5 · Build validation guards

Implement validMove()

Start with a function that accepts everything. Add rejection guards, run the test suite, and use counterexamples to discover exactly what a valid move must protect against.

Guard library

Add a rejection check

Each block becomes an if (...) return false guard. Some are useful; others will reject perfectly valid moves.

Run tests whenever you want—even with no guards. A failing case is evidence about what your function still needs.

Stage 4 of 5 · Build an iteration

Implement boardFull()

Build the tiny program that scans a board and decides whether every cell is occupied. Statement order matters, and an early return can stop the scan immediately.

Program blocks

Assemble the scan

Add statements to the function, then reorder them until the execution does what you intend. Some blocks are plausible bugs.

A good implementation can stop as soon as it finds evidence that the board is not full.
